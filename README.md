## 该选哪个

按平台选就行，同平台内没有绝对的对错：

- **Android**：先用 NekoInverter（改动保守）或 SXJ（中文优化）；偏好新界面再试 MD3 衍生版
- **iOS**：EhPanda
- **桌面 / 跨平台**：JHenTai

换版本前请先备份收藏和阅读记录，不同分支的数据格式不一定兼容。
